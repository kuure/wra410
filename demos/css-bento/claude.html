  • The grid

    Named areas make each breakpoint a small text map.

    .bento {
  display: grid;
  gap: 1rem;
  grid-template-columns: 1fr;

  @media (min-width: 64rem) {
    grid-template-columns: repeat(4, 1fr);
    grid-template-areas:
      "hero hero a11y  query"
      "hero hero code  code"
      "nest theme code code";
  }
}

.tile { grid-area: var(--area); }
.hero { --area: hero; }
